# Pruebas técnicas - Cink Coworking

Repositorio con dos ejercicios desarrollados como parte
de un proceso de selección para prácticas.

## Ejercicios

### Prueba 4 - Consumo de calefacción
Consulta de temperaturas mediante una API meteorológica,
cálculo de consumo estimado, exportación CSV y generación
automática de un dashboard HTML con ECharts.

### Prueba 5 - Uso de ventilación
Consulta de velocidades del viento mediante una API
meteorológica, cálculo del uso estimado, exportación CSV
y generación automática de un dashboard HTML con ECharts.

## Tecnologías previstas

- JavaScript
- Node.js
- API Open-Meteo
- HTML
- Apache ECharts
